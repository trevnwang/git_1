# M0 界面自检记录（CDP 驱动，两轮，2026-11-14）

> 方法：启动 `MbdGitTool.Host` 时带 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`，
> 用 Node 脚本通过 WebView2 CDP 自动点击/搜索/截图/读取 DOM；不依赖人工截图。
> 复现脚本：`artifacts/ui-review/drive.mjs`（基础）、`drive2.mjs`（全导航/可用性），均为运行时产物（gitignored）。

## 0. 两轮自检

| 轮次 | 触发 | 结论 |
|---|---|---|
| 第 1 轮 | 主动体检 | 发现并修复 4 处布局问题；核心 M0 验收项通过 |
| 第 2 轮 | **用户反馈“组件/任务/通知/邮件这些都没做，好多地方点不了”** | 属实：M0 骨架把部分导航做成了无跳转按钮。已补齐为“全部入口可达 + 占位页明确标注 M1/M2 + 行内操作有反馈” |

## 1. 第 1 轮：布局缺陷与修复

| # | 问题 | 修复 |
|---|---|---|
| 1 | 看板“操作”列被挤压成竖排单字 | 行内操作收敛为 `同步 + ⋯`（SRS §11.3），nowrap + 最小列宽 |
| 2 | CI 列文字断行 | CI 槽位固定 96px + 徽标 nowrap |
| 3 | 右侧详情面板溢出（CI 汇总条超出、HEAD 竖排） | 详情列 340px、CI 条自适应换行、字段标签列缩窄、标题省略 |
| 4 | CI 与设置都用齿轮图标 | CI 导航改 `⇄` |

## 2. 第 2 轮：可用性补齐（用户反馈项）

| 反馈 | 处理 |
|---|---|
| 组件、任务、通知、日志点不了 | 现在 7 个导航入口（看板/组件/CI/任务/通知/日志/设置）**全部有页面且可切换** |
| 设置页只有 CI 一个分区 | 设置 6 个分区（通用/工作区/认证/操作与安全/CI 集成/实验特性）**全部可切换**，内容为 M0 骨架 |
| 行内“同步/创建分支/删除”无反应 | 点击给出 **Toast 明确说明**：“M0 骨架：SYNC 将在 M1/M2 接入（需 dry-run + 备份 ref）”；`⋯` 同理 |
| 通知没有落点 | 新增**通知中心页**：3 条 Mock 通知 + CI 事件类目占位 + 未读角标 + “全部已读” |
| 任务没有落点 | 新增**任务中心空态**：说明批量操作将在 M2 接入并展示逐仓进度 |
| 组件没有独立入口 | 新增**组件列表页**：7 个 Mock 组件，点击行回看板并选中 |
| 日志/邮件没有落点 | 新增**日志与诊断页**：Mock 结构化日志 + 级别过滤 + 显示保留策略；邮件通知归入通知中心（不做邮件客户端） |
| 占位让人误以为坏掉 | 每个占位页顶部 `notice` 明确写“M0：… 将在 M1/M2 接入”，不再静默 |

## 3. 复测结果（第 2 轮，页面 reload 后干净状态）

| 检查项 | 结果 |
|---|---|
| 7 个导航点击 | **7/7 `clicked=true`**，标题依次为 组件看板/组件列表/CI 流水线/任务中心/通知中心/日志与诊断/设置 |
| 设置 6 分区点击 | **6/6 切换成功**，面板标题与点击项一致 |
| 通知未读 → 全部已读 | `2 条未读` → `0 条未读`，角标同步消失 |
| 日志级别过滤 | 全部 6 行 → ERROR 1 行 |
| 行内操作反馈 | Toast 出现且 2.5s 后自动消失（`toastGone=true`） |
| CI 10 锚点 | **10/10 命中**（含设置→CI 集成、CI 页契约） |
| 控制台错误/异常 | **0 / 0** |
| 横向溢出 | 无 |

## 5. 仍然未实现（M0 范围内属预期，且页面已明确标注）

- 真实 Gitea 同步 / 本地扫描 / 状态计算（M1）；
- GitWorker 命名管道协议、SQLite 落库（M1）；
- 批量写操作（Clone/SYNC/Tag/Delete/Restore）与任务队列（M2）；
- 真实 CI API 接入（v2，v1 只占位）；
- 邮件/系统通知渠道、MSIX 打包（M3 及以后）。

## 6. 结论

M0 的 App Shell、导航、设计 token、Mock 看板与 CI 锚点符合 SRS；**“点不动”的体验缺陷已补齐为可点击、可解释、可预期的占位页面**。
可以进入 M1（Gitea 同步 + 本地扫描 + 真实状态计算 + 看板接真数据 + 三阶段首启）。
